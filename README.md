# Tic-Pug-Toe Playtest

This repository contains the browser-ready GitHub Pages artifact for the
Tic-Pug-Toe birthday prototype and public playtest.

The site is built for `/tic-pug-toe-play/`. It intentionally contains no
development source, tests, private task records, package files, or original
reference artwork. Build provenance is recorded in `VERSION.txt`.
